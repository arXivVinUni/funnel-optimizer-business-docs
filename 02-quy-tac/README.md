# Quy tắc

Quy tắc nghiệp vụ mà agent và code phải tuân theo. Dùng mẫu `templates/quy-tac-nghiep-vu.md`.

> Trạng thái: chưa có nội dung. Nhận thẻ trên Trello để bắt đầu viết.

Danh sách tài liệu dự kiến:

- `gan-nguon-don.md` (đối chiếu SĐT, thời điểm)
- `nguong-tin-cay.md`
- `quy-tac-hitl.md` (khi nào cần người duyệt)
- `rules.yaml` (bản máy đọc được, dev import vào code)
